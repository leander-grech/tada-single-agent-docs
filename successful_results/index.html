    Successful results¶

    Curated highlights from the best checkpoints of individual runs: deterministic render clips, plus the full eval-time refusal-shield sweep over all 100 evaluation seeds. Each subsection links back to the matching entry in the experiment log, which explains what changed in that run and why — this page is the "here's what it looks like when it works" companion to that narrative.

    How this page grows

    One subsection per run, added as a checkpoint becomes worth showcasing. Each carries (1) a hyperlink to its experiment-log entry (by run number), (2) a few curated render .mp4s, and (3) the refusal-shield sweep table — a 9-row summary plus a collapsible per-seed breakdown across all 100 eval seeds. See Adding a new run for the template.

    Refusal-shield sweep (100 seeds)¶

    Does eval-time postprocessing squeeze more out of this checkpoint? A refusal shield (see MDP → eval-time action shield) is a read-only one-step look-ahead (env.peek_action): it refuses the policy's chosen clearance when that action either drops predicted reward (reward-drop) or risks a critical conflict (critical-conflict) — or both — and substitutes either do_nothing or the next_best valid clearance. Every variant is run on the same 100 eval scenarios (seeds re-seeded deterministically per reset), alongside NOOP and random baselines and the unshielded trained_raw policy.

    Columns: mean tier = mean success-tier bonus, success % = episodes flagged solved, abs_dev = mean total absolute landing deviation (s, lower is better), sep % / exit % = episodes with a separation loss / airspace exit, refusals/ep = mean shield overrides per episode.

    Raw per-episode rows: analysis/2026-06-26_shield_benchmark_1_16/results.csv (harness: analysis/2026-06-24_shield_benchmark/shield_benchmark.py).

    Per-seed sweep — total absolute deviation (s), all 100 seeds × 9 variants Columns: `raw` = trained_raw, `rd`/`cc`/`both` = reward-drop / critical-conflict / both checks, `DN`/`NB` = do_nothing / next_best fallback.
    Per-seed sweep — success-tier bonus, all 100 seeds × 9 variants

    Adding a new run¶

    To add a showcase for run N (atc_run_1_X):

    1. Renders. Drop the curated .mp4s into docs/assets/renders/ and embed them with a <video controls preload="metadata" width="100%"> block (src is ../assets/renders/<file>.mp4, relative to this page). Keep a couple of short single-episode clips inline; link the long reels.
    2. Sweep. Run the shield benchmark on that checkpoint's best model over all 100 seeds: 
      /home/leander/miniconda3/envs/tada/bin/python \
  analysis/2026-06-24_shield_benchmark/shield_benchmark.py \
  --model experiments/atc_run_1_X/best/best_model.zip \
  --seeds 100 --out-dir analysis/<date>_shield_benchmark_1_X
      then render the summary + per-seed pivots from the resulting results.csv.
    3. Cross-link. Add a ## Run N — \atc_run_1_X` best modelheading whose first line is→ Experiment log: Run N — …— theexperiments.mdheadings carry stable` anchors for exactly this.
