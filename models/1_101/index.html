    1_101¶

    complete release MDP

    What changed: Turn-legality fix: 1_76 continued for 5M steps at stage-3 settings (LR 1e-5 to 1e-6, entropy 0.001, full TMB stream distribution) with TADA_TURN_MASK_FIX=1, the corrected turn-legality mask (left and right turns were mirrored in every earlier model).

    Release MDP

    This model trained in the release MDP, unlike the champion and every model before 1_49: after each step the front of the landing queue is released once a flight is locked (predicted within 30 s of its target and in no predicted conflict). A released flight leaves the window and can no longer be cleared. It is scored in the same environment, on the same seeds and with the same metrics, so its numbers measure landings in the same scenarios, but under that extra constraint on the agent.

    About this run

    Validation 66 solved against 1_76's 59 (this card), test seeds 53 against 59: 119 against 118 over both sets, with similar losses of separation, so the fix has no measurable effect. Trained on the laptop; it replaces 1_94, the same fine-tune trained on a faulty GPU host and void. No tracker ran during training, so there is no curve.
