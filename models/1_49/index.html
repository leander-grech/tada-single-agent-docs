    1_49¶

    stopped early release MDP

    What changed: 1_48 fine-tuned in the release MDP: locked flights released from the window (±30 s), bracket paid at release, flat deviation potential, feasible-only training by redraw at reset (≤ 650 s early). Stitched 2×20 streams, LR 3e-5 to 1e-5, 300k critic warm-up, seed 49.

    Release MDP

    This model trained in the release MDP, unlike the champion and every model before 1_49: after each step the front of the landing queue is released once a flight is locked (predicted within 30 s of its target and in no predicted conflict). A released flight leaves the window and can no longer be cleared. It is scored in the same environment, on the same seeds and with the same metrics, so its numbers measure landings in the same scenarios, but under that extra constraint on the agent.

    About this run

    Stopped at 1.3M steps: redrawing infeasible training streams at reset stalled the vectorised batch (about 300 steps/s instead of 780, code commit 5c22b38). Restarted as 1_51 with a pre-screened pool of training streams. The card shows the 1M checkpoint, the only one scored.
