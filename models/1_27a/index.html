    Reproduce¶

    python analysis/score_checkpoints.py --seeds 100 --models experiments/atc_run_1_27_actionset_v2_a/checkpoints/ppo_tada_10000000_steps.zip
python analysis/attempts_to_solve.py --model experiments/atc_run_1_27_actionset_v2_a/checkpoints/ppo_tada_10000000_steps.zip --seeds 100 --max-attempts 20

    Training command: the run's run_meta.json and snapshot/ record what it ran. Runs up to 1_25 are not replayable on today's code (their observation encoding predates 1_26).
